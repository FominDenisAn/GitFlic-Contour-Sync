# Разработка

## Ветки и изменения

- Не коммитить API-токены, пароли и реальные credentials.
- Не добавлять адреса внутренних контуров как значения по умолчанию в UI.
- Все пользовательские строки должны существовать в RU и ENG локализации.
- В пользовательском интерфейсе не показывать внутренние статусы вроде `PASS`, `SOURCE`, `TARGET`, если есть нормальная пользовательская формулировка.
- Изменения синхронизации должны оставаться branch-scoped: одна явно выбранная ветка, а не `git push --mirror` всего репозитория.

## Проверка перед коммитом

```bash
npm run build
```

На Windows дополнительно:

```powershell
npm run tauri:dev
.\Build-Windows.bat
```

На Linux:

```bash
./Build-Linux.sh
```
