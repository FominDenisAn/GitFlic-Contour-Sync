# API-токены и доступы

Приложение принимает отдельный API-токен для каждого GitFlic-контура.

Токены используются Tauri backend для GitFlic REST API:

- проверки текущего пользователя;
- получения доступных проектов;
- получения веток;
- для Контура 1 - запуска и чтения pipeline проекта `devops/images-transfer`.

Токены не сохраняются в постоянное хранилище приложения.

Пользовательский токен Контура 1 должен иметь доступ к проекту `devops/images-transfer` и право запускать/читать его pipeline. Если GitFlic вернёт `403`, приложение покажет полный HTTP-ответ.

Фактический `git fetch/push` выполняется runner'ом с отдельными masked CI/CD credentials. API-токены пользователя в pipeline variables не передаются.

Не добавляйте реальные токены в README, исходники, `.env` или `gitflic-ci.yaml`.
